What you get

Four things every project comes with, no matter which platform you start on.

💬 Plain language in

Describe the change you want. MakeItOurs proposes real Python source changes, validates and builds them, and shows you a preview before anything is accepted.

📐 Exact, inspectable models

Every build opens in an interactive 3D viewer — orbit, select elements, and measure with exact dimensions, not an approximation.

📤 Export to what you already use

Download drawings for reference, or export the full model to STEP, IFC4, GLB, SVG, DXF, PDF, CSV, JSON, and Markdown for whatever CAD, BIM, or spreadsheet tool you use next.

🤝 Yours to keep and share

Every version is saved so you can always go back. Your project lives in a Git repository you control, and you can share it so others can work on it with you.

Your infrastructure, not ours

MakeItOurs doesn't run its own AI backend or hold your project hostage on a server we run. You bring your own GitHub account and your own AI provider key — OpenAI, Anthropic, Google, OpenRouter, Groq, xAI, DeepInfra, Mistral, or OpenCode — and MakeItOurs uses exactly the model you picked, never switching on its own. See Bring your own infrastructure for the full detail, or Security for exactly how credentials are transported and stored.

Mac, iPhone, and iPad — your choice

The Mac app is the faster, more capable way to manage a project: it builds and previews locally. The iPhone and iPad app is the remote option — it submits requests through GitHub Actions, so you can start and check on a project without a Mac nearby. Use either on its own, or both together on the same repository.
