Where MakeItOurs is headed

Turn a described or photographed building idea into a model you can inspect, revise, own, and take to the next step.

Pre-launch status

MakeItOurs is being tested on staging with the owner and invited testers. It is not a public customer release. The work below is planned, not shipped features or delivery dates. See release notes for verified releases.

What is built for staging

The current foundation includes a native iPhone and Mac app, hosted builds, a bring-your-own-GitHub path, a local Mac path, Git-versioned project source, and checks on generated models and files. Building exports include drawings, IFC and volume-based quantities. These are staging capabilities under test, not an offer to start a production account. A checked model is not a structural approval, building-code approval, permit set or materials shopping list.
