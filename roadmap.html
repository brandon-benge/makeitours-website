Where MakeItOurs is headed

Turn a described or photographed building idea into a model you can inspect, revise, own, and take to the next step.

Pre-launch status

MakeItOurs is being tested on staging with the owner and invited testers. It is not a public customer release. The work below is planned, not shipped features or delivery dates. See release notes for verified releases.

What is built for staging

The current foundation includes a native iPhone and Mac app, hosted builds, a bring-your-own-GitHub path, a local Mac path, Git-versioned project source, and checks on generated models and files. Building exports include drawings, IFC and volume-based quantities. These are staging capabilities under test, not an offer to start a production account. A checked model is not a structural approval, building-code approval, permit set or materials shopping list.

Remaining work before pilot

Reviewed 2026-11-23. This is a reviewed snapshot, not a live feed. Plans are not shipped features or release promises. GitHub remains the current work record; this register is refreshed through reviewed publication.

Required before pilot

  • First-time sign-up check

    One end-to-end check by a brand-new account: sign in, subscribe in the App Store test environment and create a hosted project, with no help from us.

  • Output check

    One slab and one footing on the paths the pilot uses: dimensions and volumes match expected values, and the exports open in an outside tool.

Added to staging since November 4

These are staging capabilities for the pilot, not release announcements.

  • Project visibility controls and collaborator editing for shared projects
  • Mentioning project elements with @ in chat
  • Full materials inventories
  • Hosted plans with a subscription or pay-as-you-go processing packs, and a usage balance in the app
  • A Problems page in the app for reporting a problem and following up on it
  • A clear keep time for each kind of data, listed on the privacy page
  • Hosted asks your permission before sending your requests and project content to outside AI services, and you can change that choice in your account settings
  • A time on every chat message and assistant reply, on the Mac and iPhone

Before a public launch

Planned work with no date: deleting your own account in the app, a production environment kept separate from staging, tested backups and restore, and App Store review.
