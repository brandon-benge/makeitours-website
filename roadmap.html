Where MakeItOurs is headed

Turn a described or photographed building idea into a model you can inspect, revise, own, and take to the next step.

Pre-launch status · October 2026

MakeItOurs is being tested on staging with the owner and invited testers. It is not a public customer release. The priorities below are plans, not shipped features or delivery dates. See release notes for verified releases.

What is built for staging

The current foundation includes a native iPhone and Mac app, hosted builds, a bring-your-own-GitHub path, a local Mac path, Git-versioned project source, and checks on generated models and files. Building exports include drawings, IFC and volume-based quantities. These are staging capabilities under test, not an offer to start a production account. A checked model is not a structural approval, building-code approval, permit set or materials shopping list.

First release priorities · planned

Our proposed starting point is practical residential and small-structure work: decks, pergolas, sheds, fences, gates, slabs, footings, steps, room layouts and simple built-ins. A slab and footing are proposed first proof jobs. We will test whether someone can describe or photograph an idea, clarify it, inspect and revise the model, recover from a failed attempt, and export useful drawings and volume-based quantities.

Before inviting outside users, we plan to measure request time and success on fixed jobs, improve the average request time to under two minutes without weakening checks, complete self-serve purchase and access, set pricing and usage limits from measured costs, and run a small pilot. Those outcomes have not been verified. Public feature requests and bugs are tracked in GitHub Issues; sensitive support details should go through private support.

After pilot evidence · planned

We want to add layered building assemblies, material takeoff by purchase unit with waste and optional cost, source-cited building-rule checks, clearer viewer rendering, private project sharing and comments, then opt-in public project discovery and community features. Coordinated drawing sets need jurisdiction-specific review and qualified oversight before we can promise them. These are possible next steps, not scheduled releases; the tickets carry current discussion and status.

Further exploration

Sketch markup, direct model manipulation, alternative design branches, broader photo reconstruction, richer estimating and mechanical parts may be explored later. The current product is not aimed at sculpted shapes, tight-tolerance mechanisms, appearance-led consumer products, or pipe, duct and wiring layouts.

Help shape the roadmap

Browse or discuss public feature and bug tickets. Send feature ideas to feature@bengesoftwarellc.com or use the Support page. This page explains the direction; GitHub holds work status and dates.
