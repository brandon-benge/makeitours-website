Getting Started

MakeItOurs is in pre-launch testing.

The native app and hosted service are being tested on staging with the owner and invited testers. There is no public self-serve account or App Store release yet. This page will become the customer setup guide when a release is verified. Follow the roadmap and release notes for updates.

What we are testing

The intended workflow is to describe or photograph a building idea, clarify the request, inspect and revise the model, and export checked files and drawings. Early outside-user tests will focus on simple solid-volume jobs such as a slab or footing. Generated files need independent review for the intended build; the current checks do not certify structural safety, building-code compliance, materials purchasing or permit acceptance.

Where projects can live

Staging supports hosted builds, a bring-your-own-infrastructure path using your GitHub and AI provider, and a local Mac path. Project source is versioned in Git. Self-serve purchase, production access, prices and usage limits are still being worked out and will be documented before public onboarding.

Questions or early interest?

For product ideas, write to feature@bengesoftwarellc.com. For help with a current test, write to support@bengesoftwarellc.com. Please keep private project details out of public feature or bug tickets.
