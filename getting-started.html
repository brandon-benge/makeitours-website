Getting Started

MakeItOurs is in pre-launch testing.

The native app and hosted service are being tested on staging with the owner and invited testers. There is no public self-serve account or App Store release yet. This page will become the customer setup guide when a release is verified. Follow the roadmap and release notes for updates.

What we are testing

The intended workflow is to describe or photograph a building idea, clarify the request, inspect and revise the model, and export checked files and drawings. Early outside-user tests will focus on simple solid-volume jobs such as a slab or footing. Generated files need independent review for the intended build; the current checks do not certify structural safety, building-code compliance, materials purchasing or permit acceptance.

Where projects can live

Staging supports hosted builds, a bring-your-own-infrastructure path using your GitHub and AI provider, and a local Mac path. Project source is versioned in Git. Self-serve purchase, production access and usage limits are still being worked out and will be documented before public onboarding.

See what Hosted includes and how it compares with Bring Your Own Infra. Plans and MPU packs are bought in the app; see the launch prices.

New to GitHub?

Bring Your Own Infra keeps your project in your own free GitHub account. If you have never used GitHub, this step-by-step guide shows how to sign up, protect your account, and connect MakeItOurs, what the MakeItOurs GitHub App can and can't access, and how to remove it. Rather not use GitHub at all? Hosted needs no GitHub account.

Need an AI key?

Bring Your Own Infra also uses your own AI account. This guide shows how to get an API key from OpenRouter, set a spending limit, paste it into MakeItOurs, and replace it later. Hosted includes the AI, so it needs no key.
