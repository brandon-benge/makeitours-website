# Clean Icon Composer artwork

These are independently authored 1024×1024 SVG layers, ordered back-to-front by filename. They contain geometry and flat color only: no canvas mask, baked shadow, blur, refraction, specular highlight, or Liquid Glass treatment.

- `00-background.svg` — full-bleed split color field. In Icon Composer, this can be replaced with a native canvas gradient for appearance-specific color.
- `01-blueprint.svg` — scalable blueprint structure and construction guides.
- `02-finished-house.svg` — constructed shell, roof, and deck.
- `03-house-details.svg` — glazing, deck detail, and landscaping.

Import all four files together. Their identical view boxes preserve registration automatically.
