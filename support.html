Good to know

MakeItOurs uses AI to propose design changes and can, at your direction, push those changes to your repository or permanently delete a project. A few things worth keeping in mind:

  • AI-generated changes are proposals, not guarantees. After a build, choose Rebuild, Save, or Discard Changes — Save creates a version you can always return to from Activity, where every saved version has its own Revert.
  • Destructive actions, like deleting a project repository, always require your explicit confirmation and cannot be undone by us afterward.
  • Managed subscription: MakeItOurs manages the AI, project datastore, and complete build pipeline outside your direct control. You do not need an AI provider key and cannot select the AI provider. If a managed build fails, stalls, or reports an error, email support@bengesoftwarellc.com with the project and request details so we can investigate it.
  • Bring your own infrastructure: GitHub is the source of truth for your project. You choose and pay for a supported AI provider, supply its key, and manage your GitHub repository, Actions workflows, usage, and spending. GitHub Actions adds queue and workflow latency, and troubleshooting that infrastructure remains your responsibility. Local data on your Mac is not backed up by MakeItOurs.
  • You can edit a project in another IDE, but a later upgrade could overwrite files it manages. The only files guaranteed never to be touched by an upgrade are config.py, model.py, and drawing_annotations.py — changes anywhere else are outside what we can guarantee.
